# Scripto
Проект по переводу рукописных текстов в цифровой формат. Программа позволяет распознавать рукопись с фото, надежно хранить документы в облаке и прослушивать их с помощью функции озвучки.

- Гаврилов Дмитрий: backend, нейросеть
- Закирова Сабина: frontend, дизайн
- Евдокимов Дмитрий: frontend, Android - приложение
- Ярцев Кирилл: backend, нейросеть

## Цель проекта
Разработать прототип программы по распознаванию рукописного текста, который позволяет учащимся хранить информацию в удобном для них цифровом формате.

## Технологии
- Frontend: kotlin, Figma 
- Backend: Python, JavaScript
- База данных: MySql
- Инструменты: GitHub, Android Studio, timeweb.cloud, Yandex Vision OCP, Google SMPT, Google OAuth 2.0

## Как запустить проект
1. Клонировать репозиторий: git clone [https://github.com/dag317/scripto.git]
2. Открыть папку app в Android Studio
3. Установить эмулятор (рекомендуется Medium Phone API 36.1 c Android 16)
4. Нажать Run 'app'
